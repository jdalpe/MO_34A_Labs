# Méthode de fils Monobrin (Single core)

Le fil monobrin est plus difficile a travailler que le multibrin.

Voici ses avantages:

- Contact propre
- Court-circuit très rare
- Pour de la puissance plus grande pour la même grosseur

Quelques désavantages:

- Non malléable (Un choix de heatshrink plus grand est souvent nécessaire)
- Facile a mal dégainer le fil
![](gui/badcut.jpg)

# Méthode de fils Multibrin (Multi core)

Le fil multibrin est un standard pour quelques types de connexion entre les circuits. Les batteries, par exemple, sont très souvent multibrin.

Voici quelques avantages:

- Beaucoup plus malléable
- Plus facile a adapter au circuit, les brins peuvent se placer plus facilement sur un PCB
- Seasoned un multi-core est très simple et souvent utiliser pour mieux adhérer

Le plus gros problème: Les court-circuits.. Les brins sont souvent TRÈS petit et peuvent se connecter facilement

## Méthode Parallèle

![](gui/multi_hold.jpg)

Bien enrouler les fils ensemble pour ne pas avoir de brin flottant. (Gauche - Enrouler / Droite - Flottant)

![](gui/multi_good_bad.jpg)

En parallèle, l'espace utiliser sera minimale, mais la soudure se fera en 3 étapes:

- Placer les fils parallèle

- Préparer le fil en le recouvrant d'étain

![](gui/multi_coated.jpg)

- Coller les 2 avec un soudure final

![](gui/multi_solder_a.jpg)
